# LibSpace - MUJ Library Seat Occupancy System

LibSpace is a college project designed to manage library seat availability
through a web application and QR-code-based check-in system.

## Features

- Student login and library seat availability map
- QR-code-based seat check-in and session renewal
- Study sessions with a renewal grace period
- Automatic release of seats when sessions expire
- Early checkout
- Admin dashboard for monitoring seat occupancy
- SQLite database for users, seats, and sessions

## Technology Stack

- Python
- Flask
- SQLite
- HTML, CSS, and JavaScript
- Tailwind CSS
- html5-qrcode
- Python qrcode library

## Run Locally

Create and activate a virtual environment:

    python3 -m venv venv
    source venv/bin/activate

Install dependencies:

    pip install -r requirements.txt

Start the application:

    python3 app.py

Open the local address displayed in the terminal.

## Project Structure

- app.py: Flask application and API routes
- database.py: Database creation and sample data
- templates/index.html: Student portal
- templates/admin.html: Admin dashboard
- templates/print_qrs.html: Printable seat QR codes

The local SQLite database is generated by the application
and is excluded from version control.
